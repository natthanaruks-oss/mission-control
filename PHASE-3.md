# Phase 3 Lite

## Current scope

One browser can manually back up and restore the complete Mission Control dataset to one D1 snapshot.

This is deliberately simple:

- No automatic sync
- No merging
- No roles
- No shared team board

The user always chooses whether to back up or restore, reducing the risk of silent overwrites.

## Next only after this version is stable

1. Cloudflare Access identity
2. One snapshot per user
3. Team view for Managers
4. Audit trail for assignment and priority changes

Do not add external calendar integration until identity and permission controls are in place.
